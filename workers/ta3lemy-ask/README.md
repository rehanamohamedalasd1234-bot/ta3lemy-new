# ta3lemy-ask Worker

عامل مستقل لإجابات المساعد الدراسي. لا يعدّل `ta3lemy-auth` أو عامل تحسين الرسم. النموذج مضبوط على `@cf/google/gemma-4-26b-a4b-it` عبر Workers AI binding، ومصدر الواجهة لا يحتوي مفاتيح API.

## الخصوصية والحماية

لا يسجل العامل نص السؤال في `console`، ولا يخزن السؤال أو الإجابة في قاعدة بيانات. لا يرسل المتصفح اسم المستخدم أو معرّف الحساب. الطلب محدود بحجم 7,000 بايت وبسؤال لا يتجاوز 1,200 حرف، مع حد تقريبي قدره 8 طلبات لكل عنوان IP في الدقيقة. حد المعدل المحلي متقارب وليس حدًا عالميًا صارمًا، كما أن CORS وحده ليس وسيلة مصادقة.

يجب نشر العامل فقط مع حساب Cloudflare على خطة Workers Free. الاستدلالات المجانية لها حصة يومية؛ عند استنفادها يجب أن تفشل الطلبات دون التحويل إلى فوترة مدفوعة. لا تفعّل خطة مدفوعة ولا تستخدم أي اعتماد مدفوع. إذا تبيّن أن الحساب يعمل على Workers Paid، أوقف النشر حتى إعداد سقف فوترة صريح ومراجعته.

## إعداد الخدمة بعد مراجعة المالك

1. تأكد من أن حساب Cloudflare يستخدم Workers Free وأن Workers AI متاح. لا تشغّل استدلالات تجريبية من `wrangler dev`؛ توثيق Cloudflare يوضح أن الاستدلال المحلي يُحتسب من الحصة.
2. تأكد من أن `namespace_id` في `wrangler.toml` غير مستخدم مسبقًا في الحساب. غيّره إلى رقم صحيح آخر عند التعارض.
3. من هذا المجلد، وبعد موافقة المالك على النشر فقط، استخدم Wrangler لتثبيت أحدث CLI ثم انشر العامل. لا تنشر قبل اختبار الكود ومراجعة الحد المالي:

   ```sh
   npx wrangler deploy
   ```

4. تحقق من `https://<اسم-العامل>.<نطاق-workers-في-الحساب>.workers.dev/health`. يجب أن يعيد `ready: true`.
5. بعد مراجعة عنوان العامل، ضع العنوان المنتهي بـ `/ask` في `ask-question-config.js`. لا تضع رمزًا سريًا هناك.

## API

`POST /ask` يقبل JSON: `{ "question": "...", "stage": "...", "grade": "...", "subject": "...", "style": "simple|steps|short" }`.

`GET /health` يعرض الجاهزية فقط. يسمح CORS افتراضيًا لأصل GitHub Pages الخاص بالمنصة. لا يرسل العامل سجلًا أو تاريخ محادثة.
